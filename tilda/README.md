# Выгрузка сайта на Тильду

Сайт infrahunt собран на Astro и перенесён на Тильду (проект 58806103) через её MCP-сервер. Каждая секция страницы — Vibe-блок с кодом, стили сайта — в CSS проекта, шапка и подвал — отдельные страницы проекта.

## Как обновить сайт на Тильде после правок в коде

```bash
tilda/prepare.sh                                  # копия сайта с заменами под Тильду → блоки в tilda/work/blocks
TILDA_MCP_KEY=<ключ> python3 -I tilda/push.py shared all   # загрузить изменённые блоки
```

Ключ создаётся в Тильде: «Профиль → MCP-сервер». В репозиторий его не добавлять. Стили проекта (`tilda/work/site.css`) загружаются отдельно инструментом `update_project_css_code`, после загрузки страницы нужно опубликовать.

`push.py` помнит номера страниц и блоков в `state.json` и обновляет только блоки, код которых изменился.

## Что отличается от сайта на Astro

- `overrides/` — компоненты, заменённые под Тильду: формы заявки и корзины работают через формы Тильды (получатели — в настройках сайта, раздел «Формы»), ролики открываются плеером постов Telegram.
- Код в `<head>` до оплаты тарифа недоступен, поэтому шрифты подключены через `@import` в CSS проекта, а микроразметка лежит в первом блоке каждой страницы.
- `map.json` — адреса картинок на CDN Тильды. Новую картинку загрузить через `upload_image` и добавить в карту.
- `redirects.json` — перенаправления 301 со старых адресов InSales.

Если править блоки прямо в редакторе Тильды, при следующей выгрузке из репозитория эти правки перезапишутся.
